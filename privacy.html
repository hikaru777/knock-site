最終更新日：2026年10月24日

運営者：ノック運営者（以下「運営者」）。運営者の氏名と住所は、請求があれば遅滞なくお知らせします。

連絡先：本アプリの「アカウント」→「お問い合わせ」

ノック（以下「本アプリ」）は、Mac の画面の端を通して、友達とノックし合い、同じ画面を見て、ファイルを渡すためのアプリです。このポリシーは、本アプリが扱う情報と、その扱い方を説明します。

1. 集める情報と使い道

情報 いつ 何に使うか どこに残るか
メールアドレス サインインのとき サインインと、本人確認のコードを送るため サーバー（アカウントを削除するまで）
表示名・ユーザー名・アイコン画像 プロフィールを設定したとき 友達に自分を見せるため サーバー（変更・削除するまで）
友達関係・ブロック 招待・申請・ブロックしたとき 友達とだけつながるため サーバー（解除・アカウント削除まで）
ノックの記録・メッセージ ノック・送信したとき 相手がオフラインでも後で届けるため、会話の履歴のため サーバー（アカウント削除まで）
渡したファイル ファイルを渡したとき 相手に届けるため 2人が部屋にいて直接つながっているときは、相手の Mac へ直接送り、サーバーには保存しません。それ以外のとき（相手がオフラインなど）は、サーバー（7日間。過ぎると自動で消えます）
カーソルの位置・ピン・一言の返事・集中中かどうか 部屋やノックの最中 相手の画面に表示するため 保存しません（相手の Mac へ直接送ります。直接つながらないときだけ、サーバーがその場で中継します）
見せた画面の映像 「画面を見せる」を使っている間 相手の画面に表示するため 保存しません（同上）
通報・お問い合わせの内容 通報・お問い合わせを送ったとき 運営者が確認し、返事をするため サーバー（対応に必要な間）。運営者にメールでも届きます
IP アドレス 部屋を開いたとき 相手の Mac と直接つながるため 保存しません（下の「直接の接続」を参照）

本アプリは、広告のための情報、位置情報、連絡先、他のアプリの中身は集めません。画面の映像は、あなたが macOS の選択画面で選んだウィンドウだけが対象です。アクセス解析のためのツールは入っていません。

直接の接続

部屋を開くと、本アプリはあなたの Mac と相手の Mac を直接つなぎます（WebRTC）。カーソル・一言の返事・見せた画面・部屋の中で渡したファイルは、この直接の接続で送られ、暗号化されます。直接つなぐために、次のことが起きます。

  • あなたの IP アドレスが、つながる相手（友達）に伝わります。
  • 自分の外向きの IP アドレスを知るために、公開の STUN サーバー（Google、Cloudflare）に問い合わせます。そこでは IP アドレスだけが見え、送る中身は見えません。
  • 直接つながるための情報（IP アドレスと暗号の鍵の指紋）は、友達2人しか入れないサーバーの通り道で交換します。

2. 第三者への提供

法令に基づく場合を除き、集めた情報を第三者に売ったり渡したりしません。運営のために、次の事業者のサービスを使っています。

  • Supabase（Supabase, Inc.、米国）：サーバー。上の情報はその設備（東京リージョン）に保存・中継されます。
  • Google（Google LLC、米国）：サインインのコードのメールと、運営者への通報・お問い合わせの通知を Gmail で送ります。メールアドレスと、そのメールの中身が Google の設備を通ります。
  • Google と Cloudflare の公開 STUN サーバー：直接の接続のために IP アドレスが送られます。

これらの事業者は米国の事業者です。米国の個人情報の保護の制度は、個人情報保護委員会のウェブサイト（https://www.ppc.go.jp/）で確認できます。各事業者は、自社のプライバシーポリシーに基づいて情報を扱います。

3. 削除

本アプリの「アカウント」から、いつでもアカウントを削除できます。削除すると、プロフィール、アイコン画像、友達関係、あなたが付けたブロック、招待、メッセージ、ノックの記録、渡したファイルがサーバーから消えます。他の人があなたに付けたブロックは、その人の設定として残ります。

4. 通報

不適切な相手は、本アプリからブロックと通報ができます。通報の内容は、運営者が確認し、必要に応じて利用を止めるために使います。

5. 開示・訂正・削除などのお願い

あなたの情報の開示、訂正、利用の停止、削除を求めるときや、このポリシーについて聞きたいときは、本アプリの「アカウント」→「お問い合わせ」から送ってください。ご本人であることを確かめたうえで、遅滞なく対応します。運営者の氏名と住所を知りたいときも、同じところからお知らせください。

6. 安全のための対策

サーバーとの通信と、友達との直接の接続は暗号化しています。サーバーのデータは、本人と、つながっている友達だけが読めるように制限しています。運営者が中身を見るのは、通報やお問い合わせへの対応に必要なときだけです。

7. 子どもの利用

本アプリは13歳未満の方を対象としていません。

8. 変更

このポリシーを変えるときは、本アプリまたはこのページでお知らせします。
